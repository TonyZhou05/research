Mini Royale · AI control research

CR-Harness

A simplified Clash Royale–style 1v1 battle simulator that doubles as an AI / large-model control research platform: LLM agents pick from a legal_actions whitelist at each decision_point, matches auto-record for ETL, and a web cockpit orchestrates live play plus batch evals.

简化版「皇室战争」风格对战模拟 + 大模型控制研究平台（双语 README / 文档）。
