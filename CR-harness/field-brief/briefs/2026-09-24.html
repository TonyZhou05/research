1. AutoHarness — code that owns legality candidate_intent

Lou et al. (DeepMind), arXiv:2603.03329: an LLM synthesizes an is_legal_action / propose_action Python harness via Thompson-sampling tree search over TextArena environment feedback. Reported result: 100% legal-action rate on 145 games; Flash+harness beats larger Pro on many matches. Motivation cites Kaggle GameArena chess where ~78% of Flash losses were illegal moves.

Also: TextArena, textarena.ai.

Scout iteration

  • Map CR’s existing legal_actions whitelist to AutoHarness’s verifier/proposer split.
  • Add illegal-move rate + retry-after-reject to cockpit ETL reports (model–harness config, not model alone).
  • Optional later intent: “regression-synthesize” a CR action verifier from recorded invalid attempts — human gate required.

2. PTCG-Bench — card-game harness ablations candidate_intent

Hua et al., arXiv:2605.29653 (PTCG-Bench): Pokémon TCG agents with modular harness — structured observation, legal-action masking, history. Ablation: remove masking → ~118 Glicko-2 drop, invalid-action rate ~16%. Self-evolution across rounds does not stably beat a non-evolving same-backbone baseline.

Scout iteration

  • Borrow the three-factor ablation checklist for Mini Royale batch evals.
  • Treat “self-evolving memory/prompt” as a controlled experiment — do not enable on CR without Three-Run Proof.
  • Closest public TCG shape to CR’s decision_point loop.

3. Adversarial Review — typed disagreement for dual LGTM candidate_intent

Qiu & Gill, arXiv:2608.18167: main + reviewer + critic. Naive AR fails via false consensus; forcing critic into AGREE / DISAGREE_EVIDENCE / DISAGREE_CONCERN lifts SWE-PRBench F1. Works as portable SKILL.md on SWE-bench Verified.

Scout iteration

  • Upgrade fleet blind dual-LGTM (Astra + second seat) with typed disagreement — still blind across reviewers.
  • Apply when reviewing CR cockpit / eval PRs; keep Tongli as merge gate.
  • Do not expand to five-agent MARS-style panels without cost proof.

4. Harness-Bench + Harbor — eval infra patterns watch

Harness-Bench (Qihoo360): report capability at the model–harness configuration level; flags execution-alignment failures. Harbor Adapters / Harbor-Index: adapters across 80+ agentic benches + a hard curated index (~28% ceiling for strongest reported pair).

Scout iteration

  • Sketch a thin CR adapter shape (sim + illegal rate + crown/outcome) that could sit beside TextArena later.
  • Keep public eval language aligned with harness playbook gap register.

5. MemArbiter — memory at the decision point watch

arXiv:2608.02113 — Memory-Action Gap: retrieved memory still fails to guide the current action. Five banks (Goal, Task State, Constraint, Episodic, Reference) with focal/ambient gating under token budgets. Strong ALFWorld gains; less game-specific but directly about decision_point prompts.

Scout iteration

  • Prototype a CR prompt budget: elixir + last N plays + constraints only; measure vs full match dump.

6. CR-adjacent sims (honest thin / RL) watch

Hasty-CR: CR-style sim with legal-tile masks + exploit probes — no LLM in the decision path (labeled thin for LLM research). ClashGPT: YOLO + Maskable PPO on live CR pixels — existence proof of masking in CR-shaped action spaces, not an LLM recipe.

Scout iteration

  • Steal masking + exploit-probe ideas; do not import pixel RL into CR-Harness research claims.
