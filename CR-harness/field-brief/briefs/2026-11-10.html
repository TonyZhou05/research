1 · Value-policy dissociation: LLM agents encode which action is better yet pick the worse one

watch arXiv:2611.10457 (submitted 7 Nov 2026). The authors ask whether a bad sequential decision comes from not representing future consequences or from not using them. Across Qwen2.5-7B-Instruct, Qwen2.5-32B-Instruct and GPT-OSS-20B, in a partially observed Grid environment and WebShop, the relative values of candidate actions are linearly decodable from intermediate hidden states, including at states where the policy prefers the worse action. They call this gap value-policy dissociation. Pushing along the value readout direction has limited and inconsistent effects, while Natural Value Transport (NVT), a transformation learned from the hidden-state shifts that follow real action-value differences, moves action preferences more consistently, especially at later layers. A closed-loop controller that reads value as a sensor and applies NVT as an actuator improved task outcomes.

For CR: CR cannot touch hidden states on hosted models, but the finding reframes the decision_point audit: a wrong move is not proof the model did not see the better option. Pair legal_actions logging with an explicit candidate-value readout (a scored menu step) and report cases where the stated value ranks a move above the one taken. It also fits the escalate-vs-act gate: a gap between stated value and chosen action is a cheaper trigger than raw confidence.

Suggested next step: On logged CR decision_points, ask the model to score each legal action, then count how often the chosen action is not the top-scored one and whether those states lose more.

2 · Model transitions change what an agent actually does, even with identical persona, memory and rules, and verbal compliance hides it

watch arXiv:2611.10628 (submitted 7 Nov 2026). When an agent's backend model is upgraded or swapped, operators usually reload the same persona, memory and rules and assume the behaviour carries over. The authors test that across 5,760 compliance-testing runs in 12 regulated domains with three open-weight models. Some transitions produce significant behavioural drift and others do not, even when the agent's external state is identical. Every model claims full policy compliance, yet its actual decisions under pressure differ, and the same external state can reorder which model is most compliant: a large positive effect on one substrate, negligible on the other two. The paper's recommendation is to treat model transitions as behavioural changes that need action-level testing, not transparent infrastructure swaps.

For CR: CR already argues for reporting model+harness pairs; this is direct evidence that a model upgrade under a frozen harness needs its own action-level regression, and that asking the model whether it follows the rules proves nothing. Same discipline applies to our fleet seats when a CLI model default changes.

Suggested next step: Before any model swap in CR, replay a fixed set of saved decision_points under the old and new model with the harness unchanged, and compare chosen actions, not self-reported rule adherence.
