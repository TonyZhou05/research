1. REFLEX — a measured Jev confidence gate candidate_intent

What it is. Wu & Lim (NTU), arXiv:2609.26532 (submitted 22 Sep 2026). A typed decision model (Jev, jev-1.13.0) returns a bounded choice and confidence from an allowed set; the agent executes when c ≥ τ and the action is executable, otherwise it calls a strong LLM.

Evidence. On a frozen 100-task REFLEX-Sim: 95% success vs 88% strong-only, with 72.7% fewer strong-model calls at τ=0.5 (1.12 vs 4.10 per task). Across Qwen3.8-Max, Kimi K3 and DeepSeek-V4-Pro fallbacks, strong calls drop 66–72%; the same 66 tasks are handled fully by the gate with zero failures. Limits the authors report themselves: on BFCL, choosing which function is 98.4% accurate but deciding whether to call one is 52.0%; wrong calls averaged 0.778 confidence; on τ²-bench a cheap self-escalation cascade was cheaper and not significantly worse. Increasing the action set from K=10 to 50 cost 6.7 pts accuracy; near-valid competitors shift errors between irreversible commit and deferral.

Why it matters for CR. This is the public controlled test of our jev-gameplay-decision-router idea. Mini Royale’s legal_actions list is exactly the “typed allowed set”, and a noop/wait action is the “defer” competitor.

Suggested next step

  • Adopt REFLEX’s metrics in CR ETL: coverage and risk at τ, AURC vs random escalation, strong calls per successful match.
  • Bucket decision_points by legal-action count (K) and log whether errors were commits or deferrals.
  • Always include a cheap-LLM self-escalation baseline (their B3) before claiming the gate helps.

2. Action-class calibration — Acc ≤ GAR candidate_intent

What it is. Zhao et al., arXiv:2609.00949 (1 Sep 2026). A diagnostic that splits multi-turn tool-calling failures into action-class miscalibration (picking TOOL_CALL when it should ASK/REFUSE/CONFIRM) and execution failure within the right class, using the bound Acc ≤ Gold Action Recall.

Evidence. Bound violations (Acc > GAR) expose state graders that pass trajectories with the wrong action class; the authors report this inflates standing for heavily tool-trained families. Context-only perturbations moved accuracy by up to +11.5 vs −21.0 pp in opposite directions across families on the same scenario.

Why it matters for CR. Outcome-only scoring (crowns, win/loss) can reward a “lucky” decision of the wrong kind. CR decision_points also have classes: deploy, hold/noop, escalate.

Suggested next step

  • Add an action_class field (deploy / hold / escalate) to decision_point ETL rows, separate from the action id.
  • On a small labeled set, report class recall next to match outcome; flag runs where outcome looks good but class recall is low.

3. Debate erases dissent — keep dual LGTM blind watch

What it is. Shu, arXiv:2609.26145, “Unanimity Without Persuasion”. A 7-judge heterogeneous LLM panel judges 600 code-correctness candidates, first blind and then over three debate rounds.

Evidence. Unanimity jumps from 39.5% to 95.2% after round 1 while accuracy moves by less than one point; 96.3% of verdict flips follow the displayed peer majority; by round 3 every wrong decision is unanimous. Showing labels without reasoning reproduces 91.5% of the collapse. Related: arXiv:2609.08016 finds debate changes what agents say but shows no measurable final-answer quality gain in their setup.

Why it matters for CR. Backs up the fleet rule that the two dual-LGTM seats review blind, and argues for running execution checks (tests, sim replays) before any reviewer sees another’s verdict. Pairs with Adversarial Review’s typed disagreement (2026-09-24 brief).

Suggested next step

  • In review protocol notes: record each seat’s verdict before exposure; treat post-exposure agreement as one vote, not two.

4. GameASG-Bench — spec the legal-action contract first watch

What it is. Zhang et al., arXiv:2609.21293 (18 Sep 2026). A benchmark for agents that generate browser games. Each task declares its evaluation interface before generation: legal starting scenarios, player-level actions, stable snapshots, rejection behavior, invariants. Static L1 checks and browser-run L2 checks then score it.

Evidence. 47 tasks across 12 genres, nine agent stacks. Best mean L2 check pass rate 93.2%, but best strict task success only 55.3% (26/47). Two harnesses each reached 18 strict successes, but only 10 tasks overlapped.

Why it matters for CR. Not an LLM-plays-games paper, but its interface spec maps closely onto what the Mini Royale sim must guarantee to agents: which actions are legal, how illegal ones are rejected, which invariants hold.

Suggested next step

  • Write CR’s legal_actions / rejection / invariant contract as a small executable check suite run on sim changes.
  • Report per-task strict pass, not just mean check pass, in any CR regression table.

5. AgenticSTS — bounded memory for long card-game runs idea

What it is. Cheng et al., arXiv:2607.02255 (Jul 2026; new to this brief) · project page. In Slay the Spire 2, every decision is made from a fresh message assembled by typed retrieval, with no raw cross-decision transcript, so each memory layer can be ablated.

Evidence. Adding triggered strategic skills: 6/10 wins vs 3/10 for a no-store baseline, which the authors call directional (Fisher p≈0.37). Releases 298 trajectories with frozen memory/skill snapshots and prompt records.

Why it matters for CR. A concrete bounded-prompt contract for matches with many decision_points; complements MemArbiter. Their small-n honesty is the right tone for CR ablation write-ups.

Suggested next step

  • Prototype a fixed-size decision_point prompt (state + typed recall of last N plays + one skill slot) and compare against the full-history prompt.
