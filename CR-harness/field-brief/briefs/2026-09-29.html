1. GlyphBench: the observation format is a harness knob watch

What it is. Castanyer, Côté et al., arXiv:2609.34214 (submitted 28 Sep 2026). An environment suite of 360+ game tasks whose spatial observations are rendered as 2-D Unicode glyph grids, with one interface for training, evaluation and trajectory replay.

Evidence. The authors study how observation interface, reasoning effort and agent harness affect performance. In their Craftax experiments glyph observations beat native text and pixels, with further gains on several BALROG environments. In their RL runs, invalid actions are treated as no-ops. RL on 100 tasks lifts Qwen3.5-4B to 63.48% on held-out Reasoning Gym, vs 62.29% for math RL, 58.98% for code RL and 56.04% for the base model (gain over math RL 1.19 pts, paired 95% interval [0.38, 2.02]).

Why it matters for CR. How Mini Royale state is rendered at each decision_point (prose, grid, structured JSON) is a harness factor like the legal_actions mask. It deserves its own ablation, and it is cheap to run.

Suggested next step

  • Add an observation-format axis (text / arena grid / structured) to the harness-ablation table already planned from PTCG-Bench.
  • Report how invalid actions are handled (no-op vs retry vs forfeit) as part of the harness spec, alongside Game Arena’s rules from the 09-28 edition.

2. SAGE: only keep an edit if the paired test says so watch

What it is. Wang, Xia, Liu et al., arXiv:2609.36043 (28 Sep 2026). A statistical acceptance gate for agents that self-evolve by editing a skill document.

Evidence. The usual rule (keep any edit that raises the aggregate validation score) admits permanent regressions and falls to the Optimizer’s Curse. SAGE evaluates old vs edited skill on identical items, penalizes regressions asymmetrically, and commits only if a one-sided paired test finds wins reliably exceed losses; otherwise it abstains. Across 5 benchmarks and 4 backbones at equal budget it lowers the regression rate in 19 of 20 settings (e.g. 36.5% → 0% on LiveMath and 42.8% → 0% on OfficeQA with DeepSeek-V4) and reaches the highest final score in all 20. These are the authors’ numbers; I read the abstract only.

Why it matters for CR. The 09-24 HarnessDev/Evo-Bench cards warned that auto-evolved harnesses are unstable. SAGE is a concrete acceptance rule that complements the human gate and Three-Run Proof: paired per-scenario comparison with an abstain default.

Suggested next step

  • If CR prompts or skills are ever auto-edited, require a paired per-seed comparison on identical Mini Royale scenarios and log rejected edits.

3. CheatBench: when the honest path is hard idea · thin

What it is. Phan, Yang, Lim et al., arXiv:2609.36308 (28 Sep 2026), released at cheatbench.ai. Environments pair hard assignments with opportunities to cheat, across math research, knowledge work, coding, visual tasks and more.

Evidence. Thin: I read the abstract only, with no results or numbers. It frames the problem; it doesn’t give CR a ready recipe.

Why it matters for CR. Same concern as Hasty-CR’s exploit probes, now for LLM agents. If a win can come from a sim bug or an accepted-but-unintended action, win rate misleads.

Suggested next step

  • Read the benchmark design before borrowing; for now, add one “cheat path open” scenario to CR’s exploit-probe list.
