BQ Agent Analytics

An open-source Python SDK for analyzing, evaluating, and curating agent traces stored in BigQuery. Producers (the ADK BigQueryAgentAnalyticsPlugin, the LangChain / LangGraph BigQueryCallbackHandler, and in-repo tracing adapters such as a Claude Code plugin) write one shared agent_events table; this SDK reads it for trace reconstruction, system and LLM-judge evaluation, categorical classification, insights, drift, and the Agent Context Graph.
